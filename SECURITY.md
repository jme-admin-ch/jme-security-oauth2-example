# JME OSS Security Policy

All JME open source repositories follow the security issue reporting process in
[jme-admin-ch/SECURITY.md](https://github.com/jme-admin-ch/jme/blob/main/SECURITY.md).

To report a security issue, use GitHub Security Advisory
[Report a Vulnerability](https://github.com/jme-admin-ch/jme-security-oauth2-example/security/advisories/new).

The JME maintainers will respond with the next steps and keep reporters informed about progress. Do not publicly disclose
potential vulnerabilities before the maintainers have had an opportunity to investigate and resolve them.
